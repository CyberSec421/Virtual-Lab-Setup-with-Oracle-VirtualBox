## 🔍 About the Project

This repository documents my work creating a **personal cybersecurity virtual lab** using [Oracle VirtualBox](https://www.virtualbox.org/), where I configured and explored multiple operating systems in a **safe, isolated environment** designed purely for educational purposes.

Specifically, I set up:
- 🐉 **Kali Linux**: To explore common security tools and understand their functions.
- 🐧 **Ubuntu Linux**: To familiarize myself with Linux server environments and administration.
- 🏢 **Windows Server**: To learn about enterprise system configurations and Active Directory setup.

This lab allowed me to **explore tools, systems, and network configurations** safely, without performing any attacks or offensive exercises.

> ⚠️ This project is **configuration- and exploration-focused** and is shared solely as a demonstration of my technical learning—not intended for public use or replication.

## 🧠 My Learning Process

This project demonstrates my ability to:
- Independently set up and manage a **realistic cybersecurity lab**.
- Work across **multiple operating systems and virtual networking environments**.
- Approach technical tools responsibly and ethically, focusing on **learning** rather than testing attacks.
- Develop a strong foundation for future hands-on blue team, defense, and system hardening skills.
- Take initiative to **bridge theoretical learning with practical exploration**.

As someone developing technical cybersecurity skills, I used this project to:
- Learn how to install and configure **multiple operating systems** in VirtualBox.
- Explore **Kali Linux’s toolset** without launching any active tests, focusing only on understanding tool purposes.
- Set up **Ubuntu** and practice basic system administration tasks.
- Install and configure **Windows Server** and experiment with Active Directory basics.
